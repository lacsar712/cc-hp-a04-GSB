# 饮片炮制记录台

一条记录是一整包炮制文书，里面是工序数组，不是拆成多列指标的普通表单。清炒温度和时长不在范围内就不能放行。

每包文书必须引用一条「药典章节簿」里已录入的章节：章节号与摘要句随文书存档（快照）。章节从簿中删除后，旧文书仍保留当时引用的章节号与摘要，新文书不可再挑该条。顶栏有「章节引用」链接，落地页含录入区、章节簿、已引用文书一览。

## 账号

| 用户 | 密码 | 权限 |
|------|------|------|
| processor | herb123456 | 可写（录章节、删章节、写文书） |
| checker | check123456 | 只读（章节簿与文书章节字段仅查看） |

## 启动

```bash
cd projects/14-herb-process-record
docker compose up --build
```

## 验收

1. processor 登录后，甘草为放行，黄芩为未放行（温度过低）。
2. 再写一条温度 200 的清炒，结论仍是未放行。
3. checker 看不到写入按钮，章节簿不可录入、不可删除。
4. 在章节簿录入一条章节（如 通则0214），写甘草挂该章成功，文书一览显示章节号与摘要。
5. 不挑章节直接写，前端拦截且接口返回 400 拒写。
6. 删掉该章节后，新文书的章节选择里不再有它；旧甘草行仍显示原章节号与摘要。
