# 饮片炮制记录台

一条记录是一整包炮制文书，里面是工序数组，不是拆成多列指标的普通表单。清炒温度和时长不在范围内就不能放行。

## 药典章节引用簿

- 炮制员在落地页录入药典章节（章节号 + 摘要句），章节簿对质检员只读。
- 每次写入文书必须挑一条已录入章节，未挑或挑了已删除的章节都会被拒写。
- 章节号与摘要随文书存档；从章节簿删除某条后，旧文书仍显示当时引用的章节号，新写入不能再挑该条。
- 顶栏挂章节引用簿链接，落地页含章节簿、录入区、已引用文书一览。

## 验收

1. processor 登录后，甘草为放行，黄芩为未放行（温度过低）。
2. 在章节簿录入一条章节后，写甘草并挂该章应成功；不挑章节写入会被拒。
3. 再写一条温度 200 的清炒，结论仍是未放行。
4. 删除章节簿里某条后，新写入不能再挑该条，旧甘草行仍显示原章节号。
5. checker 看不到写入按钮，也不能录入、删除章节，只能读章节簿与已有文书的章节字段。
